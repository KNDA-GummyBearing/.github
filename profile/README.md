## 한눈에 보는 설비 현황

![GummyBearing 전체 제철소 대시보드](assets/service-overview.jpg)

전체 공정에서 담당 설비까지, 필요한 상태와 점검 정보를 한곳에서 확인합니다.

## **GB System** 으로 할 수 있는 일

| 설비 상태 확인 | 모바일 경보 알림 | 점검·조치 이력 관리 |
| :--- | :--- | :--- |
| 설비별 진동 변화와 이상 징후를 확인합니다. | 경보를 휴대폰으로 받아 담당 설비를 확인합니다. | 현장 점검과 조치 결과를 기록하고 검토합니다. |

## 역할에 맞는 업무 흐름

| 현장관리자 | 설비관리팀장 |
| :--- | :--- |
| **이상 확인 → 현장 대응 → 결과 보고** | **이상 확인 → 결과 검토 → 사후 관리** |
| 담당 설비의 이상 징후를 확인하고, 현장에서 점검·조치한 내용을 기록해 보고합니다. | 전체 설비의 이상 현황과 현장 보고를 확인하고, 점검·조치 결과를 검토해 후속 정비를 관리합니다. |

GummyBearing은 **이상 징후 확인부터 현장 대응, 결과 검토와 사후 관리까지** 연결합니다.  
데이터 분석으로 도출한 판단 근거와 현장의 점검 기록을 함께 제공해 담당자의 의사결정을 돕습니다.
