## About Us

GummyBearing은 K-뉴딜 **‘설비 고장을 예측하는 AI 데이터 분석’** 과정의 팀 프로젝트입니다.

베어링 진동 데이터를 분석해 이상 징후를 판단할 기준을 설계하고, 분석 결과를 웹앱과 모바일 알림으로 연결했습니다. 현장 담당자가 경보의 근거를 확인하고 점검·정비 계획에 활용할 수 있는 서비스를 구현하는 데 초점을 맞췄습니다.

## 우리가 해결하고자 한 질문

- **무엇을 평소 상태로 볼 것인가?** — 초기 기준 구간의 안정성 검토
- **어떤 변화를 경보로 판단할 것인가?** — 특징별 기준과 누적·연속 경보 규칙 비교
- **어떤 경보가 점검 판단에 유용한가?** — 미경보 수·선행시간·지속률을 함께 평가
- **분석 결과를 현장에서 어떻게 활용할 것인가?** — 상태 확인·알림·점검 기록으로 연결

## Data & Analysis

XJTU-SY 베어링 가속수명시험 데이터를 중심으로 수평·수직 진동의 변화와 이상 탐지 결과를 분석했습니다.

| 분석 단계 | 주요 내용 |
| :--- | :--- |
| 데이터 탐색 | 베어링별·운전 조건별·측정 방향별 분포와 시계열 변화 확인 |
| 특징 검토 | RMS·Peak·첨도·파고율 검토 및 경보에 활용할 특징 선정 |
| 기준 구간 검토 | 초기 구간의 추세와 변동을 확인해 기준 설정의 타당성 검토 |
| 방법 비교 | Z-score·마할라노비스 거리·Isolation Forest 기반 이상 탐지 비교 |
| 경보 평가 | 미경보 수, 실험 종료 대비 선행시간, 경보 이후 지속률 비교 |

## Web App & Mobile

분석에서 선정한 경보 기준을 웹앱에 적용하고, 발생한 경보를 모바일 PWA의 푸시 알림으로 전달합니다.

| 기능 | 활용 |
| :--- | :--- |
| 설비 상태 모니터링 | 설비별 상태와 진동 특징의 시계열 확인 |
| 경보 근거 확인 | 기준 초과와 경보 발생 이력 확인 |
| 모바일 알림 | 웹앱에서 발생한 경보를 휴대폰으로 수신 |
| 점검 업무 관리 | 점검 내용과 조치 결과 기록, 이력 조회 및 일정 관리 |

**사용자별 활용 시나리오**

- **설비관리책임자:** 전체 공정의 설비 상태 확인, 점검 이력 조회·추출, 경보 알림 확인
- **현장관리자:** 담당 설비 중심의 상태 확인, 점검 내용 작성, 경보 알림 확인
